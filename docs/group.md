# 群聊：像群友一样聊天

`ALLOWED_CHANNEL_IDS` 里的频道由一个统一的"群友大脑"负责（`group_chat.py`）。
@、回复它的消息、喊它名字、`/ask`、平时插话，全部走同一套判断和同一份上下文。

## 它什么时候说话

| 情况 | 触发 | 行为 |
| --- | --- | --- |
| 被 @，或有人回复它的消息 | `must` | 约 1.5 秒内（等对方把话打完，最多 4 秒）一定回应 |
| 消息里提到"小D / 鲸鱼 / DeepSeek / D指导 / 大肥鱼" | `called` | 约 2.5 秒后看一眼，多半会接 |
| 它 5 分钟内在这个频道说过话 | `followup` | 约 2 秒后接着聊（不用 @，任何档位都会）；明显是别人在聊别的才不接 |
| 没人叫它，也没在聊 | `ambient` | 按话痨程度，等群里安静一会儿再决定插不插话 |

`followup` 的 5 分钟从它最后一次说话算起，每说一句就重新计时；它选择不接时不会续期，
对话就自然结束。安静模式（`!quiet`）下不算 `followup`。

话痨程度（`SOCIAL_LEVEL`，默认 1，私信里随时改）：

| 档位 | 没人叫它时 |
| --- | --- |
| 0 | 不主动插话，只回被叫到的（以及接着它刚参与的对话） |
| 1 | 安静 20 秒后考虑，距离上次发言至少 3 分钟；偶尔有话想说才插一句 |
| 2 | 安静 10 秒后考虑，间隔至少 1 分钟；像普通活跃群友 |
| 3 | 安静 5 秒后考虑，间隔至少 15 秒；很爱聊 |

没人叫它时，如果它还在想、群里又有人说话了，这次的想法作废，带上新消息重新想；
被叫到时则照常回答。

## 它看到什么

- 每个频道最近 `SOCIAL_HISTORY_MESSAGES`（50）条、`SOCIAL_HISTORY_MINUTES`（120 分钟）内的消息，
  带群友的显示名，自己说过的话也按顺序在里面（role 为 `you`）。
- 消息里的 @ 会换成名字；图片、文件、贴纸写成 `[图片 a.png]` 之类的说明（还看不懂图）。
- 回复关系：回复窗口内的消息时标出是哪一条，回复更早的消息时附上被回复的那句开头。
- 身份：宿主按用户 ID 标注 `owner`（主人）/ `member` / `you`，昵称和消息内容改变不了。
- 重启后第一次在某个频道开口前，会拉一次最近的历史（需要 **Read Message History** 权限；
  没有这个权限就从空白开始）。

## 它怎么说话

模型每次给出一个计划：0～5 条消息（一般一共 1～5 句，看话题决定）、可选的"引用回复"某条、
可选的表情回应，以及想长期记住的笔记。

- 多条消息之间按字数停顿，期间显示"正在输入"；被叫到时，思考阶段也会显示"正在输入"。
- 引用回复和表情回应都需要 Read Message History；没有权限时直接发、不引用。
- 表情可以是任意标准 Unicode 表情。
- 所有消息都禁用 @ 提醒，`@everyone` / `@here` / `<@id>` 会被打断成普通文字。
- 群里没有任何电脑操作工具。

## 节奏

- 她刚说过话的 5 分钟内，别人的消息算“可能在接着跟她聊”：等 6 秒没人再说（最多等 20 秒）才看一次，
  一串连着的消息只回一次。是否回由她决定，可以只点表情或不说话。
- 有人在打字时她会等一等（Discord 的“正在输入”）：上一条消息之后又有人开始打字，就等那条发出来
  一起看。最多多等：被 @ 12 秒、被叫名字 15 秒、接话 30 秒、没人叫她 60 秒。打字停下约 10 秒
  就当他不打了。
- payload 里有 `your_recent_share`（最近 10 条里她说了几条），说得多了她会收一收。
- 表情包至少隔 3 分钟一张，同一张不连发。

## 只有一个她：共用记忆

群里的她和私聊的她是同一个她，只是能做的事不同（私聊里她有小本子、日记、自己的房间和收图片，
群里只能聊天相关的）。

- **同一份记忆**：群聊也读长期记忆 `AGENT_MEMORY_PATH`（`data/memory.md`，只去掉“做事备忘”一节）、
  最近两个星期每天那页（`<journal>`）和更早每周一行（`<archive>`）。模型在计划里用 `remember`
  记下的群里的事，记在今天那页，标着 `[群里]`（每次最多 3 条，重复的跳过）；关于她自己的
  （`我：…`）记进长期记忆。过了两个星期回头看时，长久的会放进长期记忆。
- **翻旧事**：计划里的 `recall` 填一个关键词，宿主用一次便宜的模型调用翻更早几个星期的回忆，
  把找到的放进 `recall` 再问她一次（和 `search` 一样，一次决定里只能翻一次，没有回忆时用不了）。
  群里翻不到私聊的原话。
- **不看私聊原文**：群里的她只通过共用记忆知道私聊里的事（私聊安静后回想时记下，标着 `[私聊]`），
  不会拿到私聊的原话，这样不会把私聊细节带进群里。
- **悄悄话不乱说**：规则和她自己的记忆里都写着：私聊里的心里话、私事和你们之间的事不在群里说、
  不暗示，除非你在群里先提或者说可以。去哪了、几点回来这类日常小事可以像朋友那样说。
- 私聊那边：你发消息时，宿主会把“上次私聊之后群里的动静”附在前面，她就知道群里发生了什么。
- 以前每个服务器一份的群记忆（`data/group_memory/`）已经合并进 `memory.md`，旧文件留在
  `data/group_memory.migrated/`。`!groupmemory` 现在显示「群里的人和事」一节。

## 看图、上网、不接活

- 最近 15 条消息里的图片（最多 3 张，最新优先）会直接给模型看，每张最多约 1000 tokens。
  图片在收到消息时下载，只存在内存里。
- 需要查事实时，模型在计划里写 `search`，宿主用 DeepSeek Search API 搜一次，
  把结果放回 payload 再让模型决定怎么说（每次判断最多搜一次）。
- 群里只聊天：要代码、写脚本、做作业之类的请求，它会用性格糊弄过去，不给任何代码。

## 表情包

表情包库在 `SOCIAL_STICKER_DIR`（默认 `data/stickers/`，不进 git）：图片文件加一个目录 `stickers.json`：

```json
[{"name": "我不知道耶", "file": "deepseek-si-kao-bu-zhi-dao.png", "when": "装傻、糊弄过去"}]
```

- 目录里的名字和用途会放在群聊 system 提示末尾，模型在计划里写 `sticker: "名字"` 就会把那张图发出去
  （跟在消息后面，或者单独发）。记录里显示为 `[表情包：名字]`，避免连着发同一张。
- 需要频道里的 **Attach Files** 权限。每次请求都会重新读目录，改完不用重启。
- 私聊的小D可以用 `save_picture`（`sticker=true`）把喜欢的图加进来，也能在私聊里发表情包。
- 现在的 11 张来自 [blue-fish-archive](https://github.com/EDMOK/blue-fish-archive)（鲸鱼娘同人，
  非商业使用，版权归原作者），去掉了她的雷点“最肥”。

## 状态

群聊的她也能改自己的 Discord 状态：计划里写 `status: {"text": "服务器繁忙", "state": "idle"}`。
每 10 分钟最多改一次，payload 里的 `your_status` 告诉她现在是什么。头像、名字、简介群里改不了，
要私聊问主人。

## 私下找主人

群聊这边的小D可以在计划里写 `dm_owner`，宿主会私信发给主人（只能发给主人）。
用在：群里嘴硬、私下说真心话；群友提了好主意或约了事；群里有主人可能在意的事。

- 私信开头有一行小字 `💬 从 <服务器> #<频道> 过来私信你`，先发群里的消息，停一两秒再私信。
- 限流：两条之间至少 10 分钟，24 小时内最多 12 条。额度用完时模型会被告知（`can_dm_owner`）。
- 私信也会交给私聊那边：主人下一条私信前面会附上这条记录，私聊的小D知道那是自己说的，
  会接着聊。还没回复前重启也不会丢（`data/dm_outbox.json`）。

## 私信里管它

（需要 Personal Mode）

- `!group`：看状态（开关、话痨程度、安静模式、最近一小时请求数）
- `!group on` / `!group off`：开关群聊。关掉后被 @ 也不回，但仍记录上下文。
- `!group level 0-3`：调整话痨程度
- `!quiet 30m` / `!quiet 2h` / `!quiet off`：一段时间内只回被叫到的
- `!groupmemory`：看群记忆
- 直接说“去群里说一声……”：私信里的小D会用 `group_post` 工具以自己的身份在群里说，
  之后群友接话，群聊这边会当作接着它的话聊下去。只有一个群聊频道时不用指定频道。

这些设置存在 `SOCIAL_STATE_PATH`（默认 `data/group_state.json`），重启后保留。

## 成本和保护

- 每小时最多 `SOCIAL_MAX_CALLS_PER_HOUR`（120）次请求；被叫到的消息可以用到两倍。
  超过之后没人叫的消息直接跳过。
- 不处理其他 bot 和 webhook 的消息，所以不会和别的 bot 互相接龙。
- 用 `deepseek-flash`、JSON 输出。`SOCIAL_THINKING=true`（`.env.example` 里打开，effort 用 low）
  让她先在心里理一遍：谁说的、在说什么、是不是在跟她说、看不懂的梗要不要搜，再决定怎么接。
  每次慢几秒；思考加 JSON 偶尔会返回空白，被叫到或在接话时会自动不带 thinking 重试一次。
  思考过程（中文）会出现在 Live Monitor 的“推理原文”里。
  一次判断通常几千 tokens，
  system 提示固定不变，能吃到前缀缓存。
- 每次判断只把元数据记到 `social_decisions` 表（触发方式、结果、发了几条、token 用量），
  不记对话内容。开着 monitor 时可以实时看到思考过程和决定。
